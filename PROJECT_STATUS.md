# Project status and transparency

ClipSort is an early-stage personal open-source project.

At the time this file was created:
- The project is a small Python command-line utility.
- No public user count, download count, dependent-repository count, or external-contributor count is being claimed.
- Community feedback and contributions are welcome, but none should be assumed until they actually occur.
- Features should be considered experimental until tested on the user's own sample folders.

This file should be updated when verifiable project activity changes. Do not replace unknown metrics with estimates or invented numbers.
