# Contributing

Thanks for considering a contribution to ClipSort.

## Before you start

1. Check existing issues to avoid duplicating work.
2. For a substantial change, open an issue first to discuss the approach.
3. Keep changes focused and explain the problem they solve.

## Development setup

ClipSort uses only the Python standard library.

```bash
git clone <your-repository-url>
cd <repository-folder>
python -m unittest discover -s tests -v
```

## Pull requests

- Describe what changed and why.
- Include steps to reproduce a bug or verify a feature.
- Add or update tests when behavior changes.
- Do not include private footage, personal data, API keys, or copyrighted media.
- Be respectful and constructive in review discussions.

Contributions are reviewed by the maintainer; submitting a pull request does not guarantee acceptance.
