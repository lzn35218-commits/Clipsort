# Code of Conduct

We want participation in ClipSort to be respectful and constructive.

Expected behavior:
- Be considerate and respectful.
- Discuss ideas, not people.
- Accept good-faith feedback.
- Focus on what is best for the project and its users.

Unacceptable behavior includes harassment, insults, discrimination, and publishing another person's private information without permission.

If you experience or witness unacceptable behavior, contact the project maintainer through the contact method listed in the repository profile.
