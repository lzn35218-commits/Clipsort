# Roadmap

This is a list of possible future improvements. Items below are **not implemented unless marked complete**.

## Current baseline
- [x] Sort supported video, audio, and image files into category folders.
- [x] Preview planned moves with `--dry-run`.
- [x] Avoid overwriting files by choosing a numbered destination name.
- [x] Optional recursive scanning.
- [x] Basic automated tests.

## Possible next steps
- [ ] Add a configurable file-category mapping.
- [ ] Add a `--copy` option while keeping move as the default.
- [ ] Add a summary report that can be saved as text or CSV.
- [ ] Add more tests for unusual filenames and permission errors.
- [ ] Gather feedback from video editors before prioritizing additional features.

Roadmap priorities may change based on actual user feedback and available maintainer time.
